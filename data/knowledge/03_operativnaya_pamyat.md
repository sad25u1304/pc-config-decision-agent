# Оперативная память: объём, тип и частота

Объём памяти. Для офиса и интернета достаточно 8–16 ГБ, комфортный минимум сегодня — 16 ГБ. Для игр — 16–32 ГБ. Для видеомонтажа Full HD — 32 ГБ, для монтажа 4K — 64 ГБ. Для программирования и машинного обучения — от 32 ГБ.

Тип памяти. DDR4 и DDR5 не взаимозаменяемы: у них разные разъёмы, и модуль DDR4 невозможно установить в плату с поддержкой DDR5, и наоборот. Тип памяти должен совпадать с типом, который поддерживает материнская плата.

Двухканальный режим. Лучше ставить два одинаковых модуля (например, 2×8 ГБ вместо 1×16 ГБ): в двухканальном режиме пропускная способность памяти почти вдвое выше. Это особенно важно для встроенной графики, которая использует оперативную память как видеопамять.

Частота. Для платформы AM5 оптимальна память DDR5-6000. Для DDR4 стандартный выбор — 3200 МГц. Высокая частота заметнее всего влияет на встроенную графику и игры.
