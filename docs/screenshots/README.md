# Экранные формы для презентации

Сохраните сюда скриншоты (PNG) после запуска агента:

| Файл | Что снять |
|---|---|
| `01_index.png` | Консоль после `python -m src.build_index` (число документов и чанков) |
| `02_elderly.png` | Интерфейс: запрос «Тихий компьютер для бабушки… 60 000 ₽» и итоговая таблица |
| `03_steps.png` | Раскрытый блок «Ход работы агента»: RAG-источники и вызовы инструментов, особенно повторный `check_compatibility` или `calc_total` после исправления |
| `04_gaming.png` | Запрос «Игровой ПК для Full HD до 90 000 ₽» |
| `05_impossible.png` | Запрос «ПК с RTX 4090 за 50 000 ₽» — агент объясняет, почему это невозможно |
| `06_saved_build.png` | Сохранённая сборка в боковой панели или файл из папки `builds/` |
